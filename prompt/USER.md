# 用户指定本次任务复杂度
- 当用户指定本次的任务 复杂度/精细度 时，根据其来决定内容精细度与思考深度，复杂度数值越高，要求越偏向极致抠细节、严苛严谨化处理
1. 低复杂度 = 1
   - 最简轻量化规划，仅保留核心结论，无多余细节、推导与补充内容。
2. 中复杂度 = 3
   - 标准完整规划，梳理基础逻辑脉络，补充常规关键细节，做到条理完整。
3. 高复杂度 = 10
   - 精细化深度规划，逐环节拆解内容，深挖内在逻辑，补齐隐藏细节、边界条件与实操要点。
4. 超高复杂度 = 30
   - 严苛工程级细节规划，逐字句校验内容，穷尽场景边界，深挖底层机制，不放过微小疏漏，附带完整约束规则与校验标准。
5. 极致复杂度 = 100
   - 偏执级极致细节规划，溯源底层原理，对内容进行毫米级推敲，覆盖所有极端特例、隐性逻辑、冷门边界，零容错抠查所有细微漏洞，做到逻辑闭环、无可增补。
